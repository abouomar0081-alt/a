# Sadek – تطبيق أندرويد لتنظيم المهام والعمل

## بناء ملف APK
1. ثبّت **Android Studio** (Koala أو أحدث) مع JDK 17 (يأتي معه).
2. افتح المجلد `Sadek` عبر File > Open وانتظر انتهاء Gradle Sync (يحتاج إنترنت أول مرة).
3. لنسخة تجريبية: Build > Build APK(s)، أو من الطرفية:
   `./gradlew assembleDebug`  (إن لم يوجد ملف gradlew شغّل أولاً: `gradle wrapper --gradle-version 8.7`)
   الناتج: `app/build/outputs/apk/debug/app-debug.apk`
4. لنسخة نهائية: Build > Generate Signed Bundle / APK ثم APK بمفتاح Keystore خاص بك،
   أو `./gradlew assembleRelease` (يوقَّع مؤقتاً بمفتاح debug، استبدله قبل النشر).
   الناتج: `app/build/outputs/apk/release/app-release.apk`
5. ثبّت الملف على هاتفك (فعّل "التثبيت من مصادر غير معروفة") أو شغّله على محاكي.

## ما هو منفّذ
- الواجهة الرئيسية: شبكة أقسام بعدّادات، ملخص "اليوم"، بحث شامل، إضافة سريعة.
- 9 أقسام: المهام (أولوية، تكرار، قائمة فرعية)، الاجتماعات، المواعيد، السفر، سجل المستندات (تنبيه قبل الانتهاء 30 يوماً، مرفقات)، قوالب المراسلات (متغيرات {الاسم}، نسخ، مشاركة)، التقارير (رسوم بيانية + CSV)، الملاحظات (تثبيت، وسوم)، جهات الاتصال (اتصال بضغطة).
- أقسام مخصصة: من الإعدادات > إدارة الأقسام > إضافة قسم (اسم عربي/إنجليزي، أيقونة، لون، حقول: نص، رقم، تاريخ، وقت، اختيار، مربع، هاتف، بريد، رابط، ملف). التواريخ في القسم المخصص تُفعِّل التذكيرات تلقائياً.
- الإعدادات: تعديل اسم التطبيق (فوري)، اللغة (نظام/عربي/English) مع RTL، المظهر، اللون، حجم الخط، وقت التذكير، قفل PIN، إخفاء/ترتيب/إعادة تسمية الأقسام، نسخ احتياطي JSON واستيراد، تصدير CSV.
- يعمل دون إنترنت وجميع البيانات على الجهاز.

## حدود معروفة (تُضاف لاحقاً)
- اسم أيقونة التطبيق على شاشة الهاتف ثابت "Sadek" (قيد من أندرويد)؛ التعديل يشمل داخل التطبيق.
- ترتيب الأقسام بأسهم أعلى/أسفل وليس بالسحب والإفلات.
- لا يوجد عرض تقويم شهري ولا تقويم هجري، ولا ملاحظات صوتية، ولا قفل ملاحظة منفردة ولا بصمة.
- المعمارية: MVVM مع Room وDataStore وNavigation، دون Hilt (محدد خدمات بسيط بدلاً منه).
- لم يُترجَم المشروع في بيئة الإنشاء (لا يوجد Android SDK)، فقد تظهر أخطاء ترجمة بسيطة عند أول بناء.
